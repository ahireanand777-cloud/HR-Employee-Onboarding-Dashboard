# Nexors | HR Employee Onboarding Dashboard

## Project Overview

The **Nexors HR Employee Onboarding Dashboard** is an interactive Excel dashboard developed to analyze employee onboarding performance, task completion, document resubmissions, and monthly hiring trends.

The project demonstrates how Microsoft Excel can be used to transform structured HR data into meaningful business insights, helping HR teams monitor onboarding progress, identify bottlenecks, and improve operational efficiency.

## Data Disclaimer

The dataset used in this project is **AI-generated and synthetically created for educational and analytical purposes**.

It does not contain actual employee records or confidential organizational information. The dataset simulates HR onboarding scenarios, including employee details, onboarding tasks, document verification, and hiring activity.

All KPIs, visualizations, and insights presented in this dashboard are derived from this simulated dataset and do not represent actual organizational performance.

## Dashboard Features

### 1. Department-wise Onboarding Status
Analyzes onboarding progress across departments, including completed, in-progress, not-started, and on-hold onboarding activities.

### 2. Task Status Analysis
Provides an overview of onboarding task completion and outstanding activities.

### 3. Department-wise Resubmitted Documents
Identifies departments with higher document resubmission activity to highlight potential document quality and verification issues.

### 4. Monthly Hiring Trend
Visualizes monthly employee hiring activity and identifies periods of higher employee intake.

### 5. Interactive Slicers
Allows users to dynamically filter dashboard data using:

- Hiring Month
- Department
- Work Location
- Employment Type

### 6. Key Business Insights
Highlights important findings related to onboarding efficiency, pending employees, document quality, and hiring activity.

## Key Business Insights

- **Onboarding Efficiency:** Task completion reached 96.52%, while employee onboarding completion remained at 76.40%, indicating a gap between task execution and overall onboarding completion.
- **Pending Onboarding:** 59 employees (23.60%) remain incompletely onboarded, requiring targeted follow-ups and improved completion monitoring.
- **Document Quality:** Document resubmissions are concentrated in specific departments, highlighting opportunities to improve initial submission quality and reduce verification rework.
- **Hiring Activity:** Hiring peaked in July before declining through October, indicating fluctuations in employee intake and associated onboarding workload.
